# Prince Patel — Developer Portfolio

Production-ready responsive static portfolio for GitHub Pages.

## Highlights
- Responsive design for desktop, tablet and mobile.
- Animated developer-focused hero, project cards and interactions.
- Detailed explanations for Android and software projects.
- Certificate cards with on-click image preview and direct PDF download buttons.
- Contact section with crisp vector icons and visible labels.
- Separate Resume and CV actions.
- Student Result Management System live demo: https://pvtresult.unaux.com/
- Direct APK install buttons wired to GitHub Releases.
- Smart Expense is presented as a fully offline Android expense tracker using local device storage.

## GitHub Pages
Upload the contents of this folder to the root of the `main` branch of `prince33-dec/prince33-dec.github.io` and enable GitHub Pages from **Settings → Pages → Deploy from a branch → main → / (root)**.

## APK Releases
Create a GitHub Release and upload APK assets with these exact names:

- `Aaitravo.apk`
- `Attendance.apk`
- `MedTempus.apk`
- `NearbyReminders.apk`
- `SafeCipher.apk`
- `SmartExpense.apk`
- `TripSplitter.apk`

The website links to `https://github.com/prince33-dec/prince33-dec.github.io/releases/latest/download/<asset-name>` so the same website can keep working when a newer release is published.
